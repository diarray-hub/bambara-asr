# Draft paper section: Tokenizer training

Soloni uses a SentencePiece byte-pair encoding (BPE) tokenizer with a target vocabulary of 512 pieces. The released checkpoint retains this tokenizer; the An bɛ kalan fine-tuning script does not execute its commented-out vocabulary replacement branch. According to the experiment author's provenance, the tokenizer was trained from the **train split of RobotsMali/afvoices** using `utils/python/process_asr_text_tokenizer.py`. When supplied a manifest, that script takes each record's `text` field in input order and writes one text line per record before invoking NeMo's SentencePiece creation helper. The script does not itself deduplicate or normalize those manifest texts.

The relevant invocation sets `--tokenizer spe --spe_type bpe --vocab_size 512` and points `--manifest` to the AfVoices training manifest(s) and `--data_root` to an output directory. With the remaining options at their script defaults, character coverage is 1.0; lowercasing, byte fallback, digit splitting, extra-whitespace removal, BOS and EOS are disabled; PAD is enabled; Unicode-script splitting is enabled; all input lines are used (`spe_sample_size=-1`); no control or user-defined symbols are added; and the extremely-large-corpus mode is disabled. The NeMo helper supplies SentencePiece's other defaults, including its own default maximum piece length when the script's `spe_max_sentencepiece_length=-1` does not override it. The expected output directory name is `tokenizer_spe_bpe_v512_pad` under `data_root`.

**Provenance to resolve before publication:** the checked-in [`soloni-114m-tdt-ctc-v2` model card](https://huggingface.co/RobotsMali/soloni-114m-tdt-ctc-v2) says its tokenizer was trained on RobotsMali/kunkado train transcripts. That conflicts with the author's AfVoices-train attribution above. The released checkpoint config establishes tokenizer type and size, but does not establish which text corpus trained the tokenizer. Locate the original tokenizer-training command, manifest, or training log before making the corpus attribution categorical in the paper.
